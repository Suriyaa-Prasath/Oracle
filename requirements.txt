# Versions are pinned deliberately. Streamlit Community Cloud resolves this
# file at build time, so an unpinned ">=" stack means the deployed app runs
# code that was never tested — which is exactly how a graph that terminates
# locally ended up looping in production.
#
# Pure-Python packages are pinned exactly to the versions this project is
# tested against. Packages with compiled wheels carry a floor and a major-
# version ceiling instead, so the build can still resolve on a Python version
# that has no wheel for an older release, without silently crossing a major.
#
# Tested on Python 3.12. Community Cloud cannot change an app's Python version
# after deployment, so if you deployed on something newer and hit odd
# behaviour, delete and redeploy selecting 3.12.
